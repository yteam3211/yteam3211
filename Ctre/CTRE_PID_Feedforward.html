CTRE TalonFX: PID and Feedforward (Phoenix 6)

When using the TalonFX, we do not just tell the motor to run at 50% power. We often want to tell it to go to a specific speed or a specific angle. To do this accurately, we use PID and Feedforward.

The best part about Phoenix 6 is that these calculations happen on the motor controller at 1000Hz, making the robot smoother and more responsive.

1. Feedforward (The Best Guess)

Feedforward is the open-loop part of control. It calculates how much voltage is needed to overcome physics before we even look at the error.

Key Constants in Phoenix 6

  • kS (Static): The voltage needed just to overcome friction. If your motor hums but does not move, your kS is too low.
  • kV (Velocity): The voltage needed to maintain a constant speed. This is the most important for shooters.
  • kA (Acceleration): The voltage needed to reach a certain speed quickly.
  • kG (Gravity): Used only for arms and elevators. It provides constant power to keep the mechanism from falling down due to gravity.

2. PID (The Correction)

While Feedforward gets you close, PID uses the encoder to fix the remaining error.

  • kP (Proportional): The force. If you are far from the target, it pushes hard. If you are close, it pushes gently. Too high causes oscillation.
  • kI (Integral): The memory. It adds up small errors over time to fix steady-state error. We rarely use this in FRC.
  • kD (Derivative): The brake. It looks at how fast you are approaching the target and slows you down so you do not overshoot.

3. Implementation Code

To set these up, we use Slot0Configs. This allows you to have different slots for different gain sets.

// 1. Create the configuration object
var slot0Configs = new Slot0Configs();

// 2. Set the gains
slot0Configs.kP = 0.11; // An example value
slot0Configs.kI = 0.0;
slot0Configs.kD = 0.01;
slot0Configs.kS = 0.24; // Volts to break friction
slot0Configs.kV = 0.12; // Volts per rotation per second

// 3. Apply the configs to the motor
m_talonFX.getConfigurator().apply(slot0Configs);
