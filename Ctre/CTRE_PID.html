CTRE TalonFX: PID Control (Phoenix 6)

PID is feedback control. It looks at the difference between where the mechanism is and where you want it to be, then applies power to fix that error.

On the TalonFX, this PID loop runs inside the motor controller hardware at 1000Hz, which is much faster and smoother than running it in your robot code.

1. What is PID?

P: Proportional (The Force)

This is the most important part. The output is proportional to the current error.

  • Far from target: High power.
  • Close to target: Low power.
  • Tuning: If kP is too high, the motor will overshoot and vibrate.

I: Integral (The Memory)

It looks at the error over time. If the motor is stuck just before the target and cannot quite get there due to friction, the I term builds up energy over time to give it a final push.

Note: In FRC, we rarely use kI because it can build up too much output if the mechanism is stuck or disabled.

D: Derivative (The Brake)

It looks at how fast the error is changing. If the motor is approaching the target very quickly, the D term applies a braking force to prevent an overshoot.

Benefit: It allows you to have a higher kP for a faster response while keeping the movement smooth.

2. Setting Gains in Java

In Phoenix 6, we apply these gains to a Slot0Configs object.

var slot0 = new Slot0Configs();

slot0.kP = 0.45; // Increase for more snap or strength
slot0.kI = 0.0;  // Usually leave at 0.0
slot0.kD = 0.02; // Increase to stop overshooting

// Apply to the motor configurator
m_talonFX.getConfigurator().apply(slot0);

3. Position vs. Velocity PID

You use the same gains, but the Control Request changes based on what you want the robot to do.

Position Control (Arms, Elevators, Swerve Steering)

Moves the motor to a specific rotation.

// Move to 0.5 rotations (180 degrees if 1:1 gear ratio)
m_talonFX.setControl(new PositionVoltage(0.5));

Velocity Control (Shooters, Drivetrain)

Maintains a specific speed regardless of load, like a ball hitting the shooter.

// Spin at 60 rotations per second (RPS)
m_talonFX.setControl(new VelocityVoltage(60.0));

4. How to Tune PID Safely

  1. Start at Zero: Set kP, kI, and kD to 0.0.
  2. Increase kP: Slowly increase the value until the mechanism starts to shake or hunt for the target, then cut that value in half.
  3. Add kD: If the mechanism overshoots the target before settling, add small amounts of kD until it stops smoothly on the target.
  4. Ignore kI: For most FRC mechanisms, you can leave this at 0.0.
Safety first: Always have a teammate standing by the Spacebar (Disable) on the Driver Station when tuning PID for the first time.
