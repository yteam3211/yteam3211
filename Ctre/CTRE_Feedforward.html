CTRE TalonFX: Feedforward (Phoenix 6)

Feedforward is prediction. Instead of waiting for an error, it estimates how much voltage the mechanism should need before the motor starts moving.

This is especially useful for FRC mechanisms that fight real physics: flywheels need voltage to maintain speed, and arms need voltage to hold themselves up against gravity.

1. What is Feedforward?

Feedforward does not look at encoder error. It uses a model of the mechanism and asks, "How much voltage should this take?"

Key Constants in Phoenix 6

  • kS (Static): Voltage needed to overcome friction and start moving.
  • kV (Velocity): Voltage needed to maintain a speed.
  • kA (Acceleration): Voltage needed to speed up quickly.
  • kG (Gravity): Voltage needed to hold an arm or elevator against gravity.

2. Setting Feedforward Gains in Java

In Phoenix 6, the feedforward gains live in the same Slot0Configs object as PID gains, but this page only sets the feedforward terms.

var slot0 = new Slot0Configs();

slot0.kS = 0.24; // Volts to break static friction
slot0.kV = 0.12; // Volts per rotation per second
slot0.kA = 0.01; // Volts per rotation per second squared
slot0.kG = 0.35; // Volts to fight gravity, for arms/elevators

// Apply to the motor configurator
m_talonFX.getConfigurator().apply(slot0);

3. How to Tune Feedforward

  1. Start with kS: Raise it until the mechanism just starts moving instead of humming.
  2. Tune kV: Command a steady speed and adjust until the real speed is close to the setpoint.
  3. Add kG: For arms or elevators, adjust until the mechanism can hold position without falling.
  4. Add kA last: Use it only when acceleration matters and the mechanism lags while speeding up.
