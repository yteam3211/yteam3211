CTRE and the TalonFX

While WPILib provides the foundation, we use hardware from a vendor called CTRE, or Cross The Road Electronics. To control their motors, we use their specific library and hardware.

What is CTRE?

CTRE is the company that manufactures the motor controllers and sensors we use most often. They provide a library called Phoenix 6 that integrates with WPILib, allowing us to communicate with their hardware.

Installing CTRE

To install CTRE Phoenix 6, go to the Phoenix 6 FRC installation page and follow the instructions.

The TalonFX (Kraken X60 / Falcon 500)

The TalonFX is the integrated motor controller found inside motors like the Kraken X60 and the Falcon 500.

Key Features:

  • Integrated Controller: The brain of the motor is built directly into the back of the casing.
  • CAN Bus Communication: It communicates with the roboRIO using a daisy-chained network called the CAN Bus.
  • Built-in Encoder: It has a high-precision internal sensor that tracks exactly how many rotations the motor has completed.

Basic Code Setup

To use a TalonFX in our code, we first define it using its CAN ID and the CAN Bus name.

// Defining a TalonFX motor with CAN ID 1 on the "rio" CAN Bus
CANBus m_canbus = new CANBus("rio");

TalonFX m_motor = new TalonFX(1, m_canbus);

// Setting the motor to 50% power
m_motor.setControl(new DutyCycleOut(0.5));
