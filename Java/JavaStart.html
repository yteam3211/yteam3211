Java

"Java is C++ without the guns, knives, and clubs." — James Gosling (Creator of Java)

Java is a high-level language used in millions of applications worldwide. You might recognize Java from Minecraft or Android apps, but its reach extends everywhere—from enterprise servers to robotics.

Why Java?

  • Object-Oriented: Java is a high-level language designed around objects, making complex code easier to manage.
  • Simple yet Powerful: It offers a great balance of simplicity, reliability, and high performance.
  • Platform Independent: Java's "Write Once, Run Anywhere" philosophy means it can run on any machine—Windows, Linux, macOS, and even mobile devices—regardless of hardware strength.
  • Massive Community: Java has an enormous community behind it. Almost any problem you encounter has likely already been solved and documented online.

Java on the Y-Team

The Y-Team uses Java as the primary language for writing robot code. To join the programming sub-team, you need to master the following fundamentals:

  1. Output: How to print to the console.
  2. Variables: Understanding the basic primitive types.
  3. Objects: How to instantiate and use objects.
  4. Control Flow: Using if-else statements for logic.
  5. Loops: Using for and while loops for repetition.
  6. OOP Principles: Understanding Classes and @Override.
  7. Data Structures: Interfaces and Enums.
  8. Functional Programming: Working with Suppliers, Consumers, and Runnables.
