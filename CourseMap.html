Y-Team Programming Course Map

This is the full path from new programmer to someone who can help write, test, tune, simulate, and debug real FRC robot code. The course is meant to be completed in order, but each chapter also works as a reference during build season.

1. Basics

Java, problem solving, Git, branches, commits, and pull requests.

Start Java

2. WPILib

Robot project structure, subsystems, commands, RobotContainer, scheduler behavior, and typed units.

Start WPILib

3. CTRE And Control

TalonFX, PID, feedforward, tuning, and safe motor control.

Start CTRE

4. Sensors

Encoders, gyros, switches, beam breaks, units, offsets, and zeroing.

Open Sensors

5. Mechanisms

Real subsystem patterns for drivetrains, intakes, shooters, arms, elevators, and climbers.

Open Mechanisms

6. Autonomous

Command groups, auto chooser, PathPlanner, event markers, and auto debugging.

Open Autonomous

7. Simulation

WPILib simulation, simulated IO, mechanism sims, command testing, and visual debugging.

Open Simulation

8. AdvantageKit

Logging, replay, IO layers, AdvantageScope, and debugging without the robot.

Open AdvantageKit

9. Team Library

How to use FrcCatalyst mechanisms, generated configs, safety options, and team conventions.

Open Team Library

How To Use This Course

  1. Read the lesson page.
  2. Build the small exercise or mission.
  3. Commit your work on a branch.
  4. Ask for review before moving to the next major chapter.
  5. When possible, test in simulation before testing on hardware.
