However, you have two excellent alternatives to inject this file across your entire site so you only ever have to edit it in one place. Method 1: The Native GitHub Pages Way (Jekyll) GitHub Pages runs on Jekyll by default, which makes this the cleanest and most robust method. Create a folder in your repository named _includes. Place the generated sidebar.html file inside that folder. In your index.html (and any other pages like your CAD or software documentation pages), simply call the file by adding this snippet exactly where you want the sidebar to appear: HTML {% include sidebar.html %} Method 2: Vanilla JavaScript (Fetch) If you disabled Jekyll in your repository or prefer a pure HTML/JS approach, you can call the file dynamically using JavaScript. Place sidebar.html in the same directory as your main pages. Add a placeholder container and a short script to your pages: HTML My Site
