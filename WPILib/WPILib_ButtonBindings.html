Button Bindings

Button bindings connect driver input to commands. This is where joystick buttons, controller triggers, and default driving commands become real robot behavior.

Common Binding Types

  • whileTrue: Run a command while the button is held.
  • onTrue: Start a command once when the button is pressed.
  • toggleOnTrue: Toggle a command on and off with the same button.
  • default command: The command a subsystem runs when nothing else is using it.
private void configureBindings() {
    driverController.a().whileTrue(new IntakeCommand(intake));
    driverController.b().onTrue(new ShootCommand(shooter));

    drive.setDefaultCommand(
        new ArcadeDriveCommand(
            drive,
            () -> -driverController.getLeftY(),
            () -> driverController.getRightX()
        )
    );
}
