RobotContainer and the Command Scheduler

In the Command-Based framework, we treat Subsystems as the body and Commands as the brain. To make them work together, we use two critical components: the CommandScheduler and the RobotContainer.

1. The Command Scheduler

The CommandScheduler is a background process that runs automatically. You do not need to create it, but you must call it in Robot.java, usually inside robotPeriodic.

What does it do?

Every 20 milliseconds, the Scheduler:

  1. Polls Buttons: It checks if any buttons on your controllers were pressed, released, or held.
  2. Updates Subsystems: It runs the periodic() method of every subsystem.
  3. Executes Commands: It runs the execute() methods of all active commands and checks if they are finished.
  4. Manages Interrupts: If a new command starts that requires a subsystem already in use, the Scheduler stops the old command to let the new one run.

2. RobotContainer: The Blueprint

RobotContainer.java is where you define the shape of your robot's software. Instead of putting logic in Robot.java, you do it here.

Responsibilities

  • Creating Subsystems: Initializing your motors and sensors.
  • Configuring Controllers: Defining CommandXboxController or Joystick objects.
  • Binding Buttons: Mapping physical buttons to specific commands.
  • Autonomous Selection: Choosing which command runs when the match starts.

3. Example Implementation

Here is how a standard RobotContainer looks:

public class RobotContainer {
  // 1. Define Subsystems
  private final DriveSubsystem m_drive = new DriveSubsystem();
  private final IntakeSubsystem m_intake = new IntakeSubsystem();

  // 2. Define Controllers (Port 0 in Driver Station)
  private final CommandPS5Controller m_driverController =
      new CommandPS5Controller(0);

  public RobotContainer() {
    // 3. Set Default Commands
    // The drivetrain should always be listening to the joysticks
    m_drive.setDefaultCommand(
        new RunCommand(() -> m_drive.arcadeDrive(
            m_driverController.getLeftY(),
            m_driverController.getRightX()), m_drive)
    );

    // 4. Bind Buttons
    configureBindings();
  }

  private void configureBindings() {
    // When circle is pressed, start intake. Stop when released.
    m_driverController.circle().whileTrue(new IntakeCommand(m_intake));

    // When square is pressed once, run a shoot command.
    m_driverController.square().onTrue(new ShootCommand(m_shooter));
  }

  public Command getAutonomousCommand() {
    // Return the command to run in autonomous.
    return new AutoDriveCommand(m_drive);
  }
}
